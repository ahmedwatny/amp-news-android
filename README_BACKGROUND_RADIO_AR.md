# تعليمات تحديث AMP News

1. ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على المسارات.
2. شغّل GitHub Actions ثم نزّل Artifact.
3. اختبر تشغيل الراديو يدويًا، ثم انتقل لتطبيق آخر وأطفئ الشاشة. إشعار الراديو سيظهر أثناء التشغيل.
4. خدمة الخلفية تستخدم MediaPlayer وخدمة foreground مع WakeLock. بعض الشركات المصنّعة قد تحتاج تعطيل تحسين البطارية للتطبيق.

ملاحظة: تم تجهيز الكود لكن يلزم نجاح بناء GitHub وتجربته على جهاز حقيقي. لا تعتبر التشغيل مضمونًا قبل الاختبار؛ يعتمد ذلك أيضًا على صلاحية رابط البث وتوافقه مع MediaPlayer.
